这篇记录三个适合旅行照片再创作的图像生成方法。它们的共同点是先尊重原图的叙事焦点和色彩，再决定插画化的程度，而不是把照片简单套进一个固定模板。

下面的提示词可以在上传原图后直接复制使用；方括号中的内容按照片替换。

## 1. 用 `scenes-gathered-zine-v1-3` 转化图片

这个方法适合把一张旅行照片做成带有独立出版物气质的场景拼贴。重点不是保留照片的完整矩形，而是先判断画面里最值得讲述的部分，再围绕它设计撕口。

### 画面设计

- **构图**：只保留人物、局部水面或建筑群都可以。撕口沿着海岸、水线、树冠或建筑结构自然发展，让原始摄影和插画共同制造空间穿越感。
- **元素**：摄影区域以外出现的插画，必须来自同一个场景，不能凭空添加无关物件。
- **过渡**：撕口附近先保留原照片的色彩和细节，再逐渐转成网点、干刷或丝网印刷效果。用一条连续的色彩或运动轨迹跨越摄影区和插画区。
- **禁止项**：不要使用矩形贴图、均匀白边或明显的数码蒙版边缘。

### 提示词示例

```text
使用 scenes-gathered-zine-v1-3 转化我上传的照片。先判断这张照片的叙事焦点，以[人物 / 水面 / 建筑群等主体]为中心设计不规则撕口，不预设照片的固定占比；允许只保留有叙事价值的局部。

让撕口沿原图中的海岸、水线、树冠或建筑结构自然发展。摄影区域外的插画只能延伸原图里的同一场景，不添加不相关的元素。撕口边缘先保留原照片的色彩和细节，再逐渐过渡为网点、干刷或丝网印刷质感。用一条连续的色彩或运动轨迹跨越摄影和插画区域，形成空间和层次穿越感。

不要矩形贴图、均匀白边或数码蒙版感。
```

## 2. 竖向二分构图的哑光米白画册明信片

这是一种更克制的东方建筑风景版式。它适合想保留原照片辨识度，同时得到一张像画册内页或研究卡片的场景明信片。

### 版式与质感

- 画面采用**竖向二分构图**。
- **上半区：实景摄影**。严格保留高清写实风景的原貌，沿用原始景物的空间布局、物理轮廓和低饱和度配色，不改变原生光影质感。
- **下半区：水墨重构**。使用独立的米色留白区域，提取上半区的全部景物并解构成极简几何形态。用分层平涂的柔和色块结合毛笔淡墨晕染，避免锐利硬边。
- 下半区复刻原图的整体色彩调性，但剔除细碎纹理、冗余杂物和复杂光影，只保留纯粹的结构神韵。
- 画面最底端居中排版：首行为优雅的衬线手写体英文标题，次行为字号更小的无衬线英文描述短句。
- 以米白哑光特种纸为底色，大面积留白，整体干净、克制、高级并具有学术感，不添加多余装饰。

### 提示词示例

```text
基于我上传的风景照片，制作一张竖向二分构图的哑光米白画册明信片。

上半区是高清写实摄影：严格保留原图景物的空间布局、物理轮廓、原生低饱和度配色和光影质感，不改动原始风景。

下半区是独立的米色留白区域，放入对上半区全部景物的水墨扁平重构。把景物解构为极简几何形态，以分层平涂的柔和色块和毛笔淡墨晕染呈现，不使用锐利硬边。复刻原图的整体色调，但去掉细碎纹理、冗余杂物及复杂光影，只留下结构神韵。

在画面最底端居中排两行英文：第一行用优雅的衬线手写体写“[英文标题]”，第二行用更小的无衬线字体写“[英文描述短句]”。整体是米白哑光特种纸质感、大面积留白的极简东方建筑风景研究版式，干净克制，不加多余装饰。
```

## 3. 超现实主义：`@ice cream: surreal pop collage`

这个方向更适合海报化的主体肖像或旅行纪念照。它通过平面色块、一个巨型超现实元素和一组弧形小元素，制造醒目的视觉叙事。

### 生成约束

- **尺寸**：纵向 `3:4`。
- **主体**：保持主体清晰可辨，保留原始颜色。需要时补充细节约束，例如“双手空着，不拿道具”。
- **背景**：替换为巨大的平面哑光色块，例如深祖母绿色和暖棕色的不规则色形，使用两到三个颜色即可。
- **超现实元素**：只放置一个不可能的巨型元素，而且必须源自原图；再添加一组沿弧形排列、尺寸渐变的小元素，并配几条白色手绘涂鸦线条。
- **风格限制**：平面哑光色彩，无渐变、无阴影、无文字、无水印。

### 提示词示例

```text
把我上传的照片制作成 @ice cream: surreal pop collage 风格的超现实主义海报，纵向 3:4。

保持[主体]清晰可辨，保留主体的原始颜色。[可选细节约束，例如：双手空着，不拿道具。]

把背景替换成 2-3 个巨大的平面哑光不规则色块：[色块一及颜色]、[色块二及颜色]、[可选的色块三及颜色]。只加入一个不可能的巨型元素：[原图中已有的物体]的巨大化版本；再让[原图中已有的小元素]沿弧形排列，尺寸逐渐变化，并添几条白色手绘涂鸦线条。

整体使用平面哑光色彩，不要渐变、阴影、文字或水印。
```
